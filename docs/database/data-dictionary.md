# FinGuard AI — Synthetic Banking Dataset Data Dictionary (Phase 2)

## 1. Overview
This document details the data dictionary for all synthetic banking and fraud datasets generated by the **FinGuard AI Transaction Simulator**.

All data is generated with deterministic pseudorandom seeds, adhering to standard Indian and international banking topologies. Reserved IP address blocks (RFC 5737: `192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24`) and synthetic customer identities are used to prevent collisions with real individuals or infrastructure.

---

## 2. Dataset Specifications

### 2.1 `customers.csv`
Synthetic retail and corporate banking customer demographic profiles.

| Column | Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `customer_id` | String (PK) | Unique customer identifier | `CUS-200045` |
| `first_name` | String | Customer given name | `Aarav` |
| `last_name` | String | Customer family name | `Sharma` |
| `email` | String | Customer email address | `aarav.sharma45@example-bank.test` |
| `phone` | String | Customer registered mobile number | `+919812345678` |
| `risk_segment` | String | Demarcated wealth/risk profile (`LOW`, `STANDARD`, `HIGH_NET_WORTH`) | `STANDARD` |
| `kyc_status` | String | Know Your Customer verification status | `VERIFIED` |
| `country` | String (2) | ISO 3166-1 alpha-2 country code | `IN` |
| `city` | String | Customer primary residential city | `Kolkata` |
| `created_at` | Timestamp | Account profile registration timestamp | `2025-01-15T00:00:00Z` |

### 2.6 `fraud_labels.csv`
**Ground-Truth Labels (Isolated from Feature Vector to Prevent Target Leakage).**

| Column | Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `transaction_id` | String (PK/FK) | References `transactions.transaction_id` | `TXN-20261112-100001` |
| `is_fraud` | Integer (0 or 1) | Binary classification ground truth (1 = Fraud, 0 = Normal) | `1` |

---

### 2.7 `transaction_features.csv`
**Predictive Feature Store Dataset (ML-Ready, Strict Zero-Leakage).**

| Column | Type | Description | Range / Bounds |
| :--- | :--- | :--- | :--- |
| `transaction_id` | String | Unique identifier for join | `TXN-20261112-100001` |
| `transaction_amount` | Float | Nominal transaction value | $[10.0, 500000.0]$ |
| `avg_amount_24h` | Float | Rolling average of transactions over past 24 hours | $[10.0, 500000.0]$ |
| `transaction_count_5m`| Integer | Count of transactions from account in last 5 minutes | $[0, 20]$ |
| `transaction_count_1h`| Integer | Count of transactions from account in last 1 hour | $[0, 50]$ |
| `amount_deviation` | Float | Ratio of current amount to 24h baseline | $[0.01, 50.0]$ |
| `new_device` | Integer (0/1) | 1 if device unseen in customer device registry | $\{0, 1\}$ |
| `location_change` | Integer (0/1) | 1 if location changed within preceding 2 hours | $\{0, 1\}$ |
| `international_flag` | Integer (0/1) | 1 if cross-border payment | $\{0, 1\}$ |
| `merchant_risk` | Float | Historical risk weight of merchant category | $[0.01, 0.99]$ |
| `account_age_days` | Integer | Account tenure in days | $[60, 1000]$ |
